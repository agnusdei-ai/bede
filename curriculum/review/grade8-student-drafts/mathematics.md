## Week 1: Signed quantities and a reference point

Lesson: `g8-year-mathematics-w01` · Draft version 1

### Learning focus

Apply and explain signed quantities and a reference point using the specified independent and transfer tasks.

### Before starting

### Explicit Teaching

Suggested time: 12 minutes.
