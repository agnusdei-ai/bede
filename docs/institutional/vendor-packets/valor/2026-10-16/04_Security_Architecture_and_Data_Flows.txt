-> PostgreSQL and encrypted record services -> configured model adapter (either local model or approved cloud API).
Separately enabled voice, email, image lookup and licensing services can create additional outbound flows. This is a
design description, not evidence that each control passed a deployed campus test.

Minimum security evidence Valor should request
   Exact release SHA, artifact integrity and SBOM; supported browsers and device inventory.
   Architecture and data egress diagram for the actual deployment, including every enabled cloud API and
    subprocessor.
   Campus isolation, session revocation, consent/guardian checks, input safeguards, assessment integrity and
    security log review.
   Signed operational plan for keys, encrypted backups, offsite copies, restore, incident response and secure
    disposal.
   Accessibility, load and device verification for agreed enrollment and simultaneous usage; no assumed unlimited
    throughput.
  REVIEW NOTE The phrase "data stays on site" is accurate only for a proven local, properly isolated configuration.
  The public demo and certain optional features use external services.
