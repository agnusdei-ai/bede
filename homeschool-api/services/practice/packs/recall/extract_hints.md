# Reading a short-answer or multiple-choice quiz

- Copy each question into `prompt` exactly as printed, including any blank
  (`___`). For multiple choice, include the options in `prompt`
  (e.g. "Who wrote the Declaration? A) Adams B) Jefferson C) Franklin").
- Copy the child's answer exactly into `student_response`. For multiple choice
  record the letter they chose.
- Copy any answer the teacher wrote into `teacher_correction`. If an answer key
  is printed on the page, use it for a question marked wrong.
- A tick means correct, a cross incorrect, a half tick or "½" partial.
- If a word or letter is hard to read, give your best reading, lower
  `confidence`, and say what is unclear in `ask_parent`.
