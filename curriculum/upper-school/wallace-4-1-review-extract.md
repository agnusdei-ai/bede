## Example 165: test a proposed common solution

System: `3x − y = 5` and `x + y = 3`.
Proposed solution: `(2, 1)`.

Substitute both coordinates in both equations:

- `3(2) − 1 = 6 − 1 = 5`.
- `2 + 1 = 3`.

Both statements are true, so `(2, 1)` is a common solution. Testing a point in
only one equation is insufficient.

## Example 166: graph two lines

System: `y = −(1/2)x + 3` and `y = (3/4)x − 2`.

For the first line, use `(0, 3)` and `(4, 1)`.
For the second line, use `(0, −2)` and `(4, 1)`.
Draw each line on the same axes with consistent scales.

The lines intersect at `(4, 1)`. Verify:

- `−(1/2)(4) + 3 = −2 + 3 = 1`.
- `(3/4)(4) − 2 = 3 − 2 = 1`.

The pair satisfies both equations. A rough drawing locates a candidate;
substitution checks the candidate exactly.

## Educator note added by Bede

Do not generalize the surrounding introductory discussion into a rule that two
equations always determine a unique solution. Distinct parallel lines have no
common point; equations describing the same line have infinitely many common
points. The Week 10 lessons explicitly teach those cases.
