# Bede's words

Use these words, spelled this way, in docs, app copy, the site and the demo.
Where a generic phrase and one of these mean the same thing, use the one
here. Internal ids and stored values keep whatever name they already have.

| Say | Meaning | Instead of |
| --- | --- | --- |
| **pod** | The learners who study together under one plan: a household, a co-op group, a tutor's group or a small class. Up to ten. | small group, cohort (when it means the learners), class group |
| **learning sprint** | One focused block of work on one subject, followed by a break. 20 minutes by default; the length may vary by learner (for example a younger learner, or one whose parent or teacher knows a shorter or longer block suits them). A session is one or more learning sprints. | study block, focused block, work period |
| **session** | One sitting with Bede, from sign-in to the summary. It has a parent-set length and a required break each hour. | lesson (for the whole sitting) |
| **lesson** | One subject's part of a session. | class, period |
| **mastery cycle** | The rolling window (28 days unless travel mode widens it) over which a parent sees whether a topic moved. It limits how far back Bede looks. It is never a deadline for the child. | sprint, grading period |
| **work ledger** | The record of what a learner actually completed, with dates and how much help it took. Events, never a score. | activity log, gradebook |
| **mastery picture** | The estimate of which skills are secure, by area, on the Progress page. | grades, levels |
| **narration** | The learner telling back, in their own words, what they read or heard. | recap, summary (by the child) |
| **Morning Time** | The opening subject: prayer, Scripture reading, poetry and a hymn. | opening block |
| **living books** | Whole, well-written books read for their own sake. | readers, texts |
| **picture study** | Looking closely at one artist's work, putting it away and telling it back. | art appreciation |
| **composer study** | Listening to one composer's work with a guide to what to notice. | music appreciation |
| **Practice Coach** | A graded quiz turned into parent-approved practice. | remediation tool |
| **Teacher Quiz Studio** | A teacher's own quiz, its answer key, printing and scoring. | quiz maker |
| **Data Day** | A campus's scheduled day for reviewing assessment results (Q1 to Q4). | benchmark day |
| **companion mode** | The setup preset for how much of the day Bede leads: Book Companion, A Bit More Structure, Full Daily Plan. | plan type |
| **what helps this child** | The parent's list of what makes a lesson go better for one learner. | accommodations list, needs |
| **Watch, Together, Your turn** | The three steps of a practice routine. | I do, we do, you do |
| **guide** | What Bede is. The parent or teacher teaches; Bede guides and reports what it saw. | teacher, tutor (for Bede's role toward the adult) |
| **suggestion** | What Bede proposes to a teacher before the teacher decides. | recommendation (in teacher-facing copy), diagnosis |
| **learner** | The child or student, in school and pilot material. Family material may say "child". | user, pupil |

## Two rules

1. **A learning sprint is about the clock in one sitting. A mastery cycle is
   about what a parent looks back over.** Do not use "sprint" for the mastery
   cycle, and do not attach a date or a target to a learning sprint. Bede
   never hurries a child.
2. **A pod is never ranked.** Anything that describes a pod describes who
   did which work, not who is ahead.

## Where this is not applied yet

The marketing site and the demo change only with the owner's sign-off. Two
places there still use the generic phrase: the home page photo's description
("a small group of children") and the research page's "sprints", which a
demo test pins word for word.
